# 合租小窝 · roommate-life

合租生活管理（本机演示版）：费用 AA、清洁值日、公共物品补货、室友公约，以及首页待办汇总。

正式网址：**https://echo-dawn.github.io/roommate-life/**

## 产品定位

给一起合租的室友一个轻量的「共同账本 + 值日表 + 公共物品清单 + 公约」。
本仓库当前是**本机演示版**：所有数据保存在当前浏览器的 localStorage 中，不需要注册登录，打开即用。

## 首版能力

- **费用 AA**：按整数分记账；平均分摊余数按固定成员顺序分配（保证合计严格等于总额）；支持自定义金额（合计必须与总额完全一致）；付款人可不参与分摊；提交前有分摊预览；按月份 / 分类 / 我的结算状态筛选。
- **结算链路**：待付款 → 付款成员标记已付 → 待收款人确认收到 → 已结清。每一步只能由对应身份操作；已结清不能重复确认；未结清份额可提异议（保留原结算状态并暂停操作），提出者可撤回，操作留痕。
- **作废规则**：仅创建者在无人标记付款、无人结清时可作废；作废记录保留但不再计入汇总。
- **清洁值日**：规则包含区域、完成标准、每周执行日、成员顺序、起始日期；负责人按「起始日期 → 目标日期」的实际排班次数轮换，与浏览的周无关；同一规则同一日期最多一个任务；过期任务保留原负责人并标记「待补做」。
- **换班**：从自己的未完成任务发起，选择另一位室友的未完成任务；双方任务不得过期、不得已完成、不得涉及其他待确认换班；被邀请人接受后两项任务的负责人一次性交换；拒绝或撤销不影响原排班；接受时会重新校验。
- **公共物品**：登记、更新余量、认领补货、取消自己的认领、完成补货（余量恢复满量并生成记录）；已有认领时他人不能重复认领；补货完成后可「同时记一笔」，自动预填并关联账单，同一补货记录最多关联一笔有效费用。
- **室友公约**：条款化内容（安静时间、访客留宿、公共区域、费用结算、清洁标准、物品购买）；支持编辑草稿、提交新版本、逐人确认、版本历史；同时最多一个待确认版本；全员确认后生效，旧版在此之前继续有效；发起人可撤回后重新编辑。
- **首页待办**：汇总当前身份的待付款 / 待收款（含待确认部分）、今日值日与待补做、需补货物品、待确认收款 / 换班 / 公约，全部来自真实演示数据，可点击进入对应事项。
- **身份切换与重置**：三位虚构室友（小林 / 小周 / 小陈）一键切换；重置只清除本应用的存储项。

## 本机演示与真实多人协作的区别

| | 本机演示版（当前） | 真实多人协作（未实现） |
| --- | --- | --- |
| 数据存储 | 单个浏览器的 localStorage | 服务端数据库 |
| 成员身份 | 前端切换虚构身份，无鉴权 | 真实账号与登录 |
| 数据同步 | 不同步，换浏览器 / 清缓存即丢失 | 多人实时共享同一份数据 |
| 操作校验 | 仅前端校验 | 服务端权限校验 |
| 消息通知 | 无 | 提醒、推送 |

演示版**没有**实现真实账号、多人同步、支付和外部消息推送；页面上的相关流程只用于展示交互与规则。

## 本地开发

```bash
npm install     # 安装依赖
npm run dev     # 本地开发（http://localhost:5173/roommate-life/）
npm test        # 运行单元测试（金额、分摊、轮换、状态转换）
npm run build   # 类型检查 + 构建到 dist/
npm run preview # 预览构建产物（http://localhost:4173/roommate-life/）
```

技术栈：React 18 + TypeScript + Vite，路由使用 HashRouter（保证 GitHub Pages 深链接刷新可用），未引入 UI 框架。

## 数据保存与重置

- 数据保存在 `localStorage`，键名前缀为 `roommate-life:`（当前为 `roommate-life:state`），包含 `schemaVersion`，未来版本会带迁移逻辑。
- 首次打开写入示例数据；已有数据不会被覆盖。
- 数据损坏时页面会给出恢复提示（可先下载原始数据备份），不会静默清空。
- 存储不可用或写入失败时页面会明确提示，不会虚报保存成功。
- 重置：侧边栏 / 小窝页的「重置演示数据」，仅清除 `roommate-life:` 前缀的键，不影响同域名下其他应用。

## 更新与发布

1. 修改代码后本地执行 `npm run build`、`npm test` 验证。
2. 提交并推送到 `main` 分支。
3. GitHub Actions（`.github/workflows/deploy.yml`）会在 `main` 推送时自动执行类型检查、测试、构建，并通过 GitHub 官方 Pages artifact 部署；也支持在 Actions 页面手动触发（workflow_dispatch）。
4. 仓库 Pages 设置使用 **GitHub Actions** 作为来源，网址保持 https://echo-dawn.github.io/roommate-life/ 不变。

## 当前限制

- 仅本机演示：数据不同步、无真实账号、无服务端校验。
- 清除浏览器站点数据、使用隐私模式或更换设备都会丢失数据。
- 不支持支付、消息推送、附件上传、图片等富内容。
- 值日轮换按规则内成员顺序计算，修改规则成员顺序只影响之后的排班判断。
- 示例数据（向阳小窝 · 小林 / 小周 / 小陈）为虚构内容，不含真实个人信息。
